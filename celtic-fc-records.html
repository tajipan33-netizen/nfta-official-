기록은 현재 브라우저의 로컬 저장소에 보관됩니다. 기기를 바꾸기 전에 JSON을 내보내 보관하세요. JSON 가져오기는 기존 로컬 데이터를 교체합니다.

이 웹 파일은 독립형 기록장입니다. 브라우저에서 직접 열면 기기별 로컬 저장소를 사용합니다. 여러 기기에서 공유되는 중앙 저장소는 Supabase SQL 마이그레이션을 적용하고, 앱에 URL과 publishable key를 설정해야 활성화됩니다. service_role 키를 여기에 입력하지 마세요.
